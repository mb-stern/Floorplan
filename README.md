# 🏠 Floorplan für IP-Symcon

Ein interaktiver Grundriss-Editor für **IP-Symcon**. Räume, Wände, Türen, Fenster, Objekte, Formen und Geräte lassen sich direkt im Browser platzieren und anschließend in der Visualisierung anzeigen und bedienen.

Die vollständige Dokumentation mit Funktionsbeschreibung, Installation, Bedienung und Versionshistorie befindet sich in der [Moduldokumentation](FLOOR/README.md).

## Installation

Das Modul kann über den **IP-Symcon Module Store** installiert werden. Anschließend eine **Floorplan-Instanz** anlegen, den Editor öffnen und den Grundriss erstellen.

**Voraussetzung:** IP-Symcon ab Version 8.2.
